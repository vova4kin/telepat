# Telepat plugin marketplace for Claude Code

One-command install:

```
/plugin marketplace add vova4kin/telepat
/plugin install telepat-watch@telepat
```

## Plugins

- **telepat-watch** — mirror Claude Code sessions to a Galaxy Watch
  (Approve/Deny tool calls from your wrist).
  See [vova4kin/telepat-watch](https://github.com/vova4kin/telepat-watch).
